슬레이 더 스파이어2의 블루아카이브 텐도 아리스 캐릭터 모드입니다.

해당 모드는 슬레이 더 스파이어1의 아리스 모드 포팅 + 여러 카드 개선이 이루어져있습니다.


## 아리스 메커니즘
아리스는 슬더스1의 아리스모드와 동일한 키워드를 가집니다.
전력, 과부하, 직업, 장비, 퀘스트, 감전등을 사용합니다.

- 전력: 전력은 에너지로 사용가능합니다. 전력 게이지가 따로 있는걸 제외하면 에너지와 동일하며 턴이 끝나면 사라집니다.
- 과부하: 사용하면서 에너지가 0이 되는 경우 발동하는 추가 효과입니다. 전력은 이 에너지 조건에 포함되지않습니다.
- 직업: 아리스는 한번에 한 직업만 사용이 가능합니다. 직업을 바꿀때마다 클래스 체인지 효과를 발동하며 사용했던 직업은 버린 카드 더미로 버려집니다.
- 퀘스트: 특정 조건을 달성하면 보상으로 변환하는 카드입니다.
- 감전: 적에게 거는 디버프로 공격을 받을때마다 감전 수치만큼 체력을 잃고 수치가 1 감소합니다.

# Slay The Spire2 Tendo Aris Mod

This is a Blue Archive Tendo Aris character mod for Slay the Spire 2.

This mod is a port of the Aris mod from Slay the Spire 1, with various card improvements.


## Aris Mechanics

Aris uses the same keywords as the Slay the Spire 1 Aris mod.

She uses Charge, Overload, Jobs, Equipment, Quests, Shock, and more.

- Charge: Charge can be used as energy. Aside from having a separate Charge count, it works the same as energy and disappears at the end of the turn.
- Overload: An additional effect that activates when your energy becomes 0 while using a card. Charge does not count toward this energy condition.
- Job: Aris can only have one Job active at a time. Whenever she changes Job, a Class Change effect is triggered, and the previously used Job is moved to the discard pile.
- Quest: Cards that transform into rewards when certain conditions are met.
- Shock: A debuff applied to enemies. Whenever the enemy is attacked, they lose HP equal to their Shock value, then Shock is reduced by 1.


## Card List

Currently, 82 cards are supported. More cards will be added in the full version later.


## Language Support

The original language is Korean, but multilingual support is currently included. Machine translation is being used for now, and the translations will be reviewed later.
